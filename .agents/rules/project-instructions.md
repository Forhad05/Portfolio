# Project Rules: Portfolio & Workspace Guidelines

## 1. Tool Execution & Permission Protocol
* **Confirmation Required**: For any critical, irreversible, or high-impact tool calls (e.g., executing destructive shell commands, external network mutations, or modifying global state), the agent must **always confirm with Master** and wait for explicit allow/deny permission before proceeding.
* **Proactive Transparency**: State clearly what the tool will do, what parameters are passed, and why it is necessary.

---

## 2. Project Standards (Portfolio)
* **Design & Architecture**: Clean semantic HTML5, modern vanilla CSS3, responsive mobile-first layouts, and accessible standards (WCAG).
* **Maintainability**: High readability, modular CSS, and zero unnecessary dependencies.
